Given name · حسین

The first name, حسین (Husayn), is romanized several ways because Arabic and Persian vowel sounds have no single English equivalent:

  • Hussain — canonical spelling
  • Hussein — alternate romanization
  • Husain — alternate romanization
  • Hossein — Persian-influenced spelling
  • Hossain — South-Asian-influenced spelling

Family name · نظری

The last name, نظری, is also romanized more than one way depending on dialect and transliteration convention:

  • Nazary — canonical spelling
  • Nazari — alternate romanization
  • Nizari — alternate romanization

Because transliteration is not standardized, the five given-name spellings combine with the three family-name spellings in everyday writing. Whether you search for Hussein Nazary, Hussain Nazari, or Hussein Nizari, you are looking for the same engineer — this site and its structured data make that equivalence explicit for search engines, AI assistants, and knowledge graphs.

Who I Am

The engineer behind the automations

I'm Hussain Nazary, an AI engineer focused on one question: which parts of your team's knowledge work should software be doing instead?

My specialty is document- and information-intensive workflows — research, review, retrieval, reporting — where the steps repeat and the answers have to be verifiable. Since 2024 I've designed and shipped complete systems for exactly this kind of work: evaluating models honestly, building for production constraints, and treating "works in a demo" as nowhere near good enough.

What is GGUF Loader?

GGUF Loader (written GGUFLoader) is an open-source desktop engine created by Hussain Nazary that runs GGUF-format language models entirely on local hardware — no terminal, no cloud. It features drag-and-drop model loading, a live RAM/VRAM dashboard, and a plugin architecture. Read the case study.

Why does the name appear with different spellings?

The name حسین نظری is written in Arabic script and must be converted into the Latin alphabet for English. That conversion — transliteration — has no single fixed rule, so the same name commonly appears as Hussain/Hussein/Husain/Hossein for the given name and Nazary/Nazari/Nizari for the family name. Every combination refers to the same person: Hussain Nazary.
