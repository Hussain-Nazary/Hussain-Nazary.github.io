## Per-post workflow (repeat for every post)
1. Research: 2–4 web searches + read 1–2 authoritative sources. Save the verified facts.
2. Outline: H1 + 5–7 H2 sections + table or list where it earns its place + FAQ (3–6 Q&As, mirroring the JSON-LD).
3. Write 600–1,200 words, plain English, concrete, sourced. No AI-slop filler.
4. SEO head: title, description ≤160, keywords, canonical, OG/Twitter, BlogPosting + FAQPage JSON-LD.
5. Internal links + conversion box at the end.
6. Add to `_wire_posts.py` POSTS list (filename, category, short label) + tracker row (status=planned).
7. Run `python _wire_posts.py` → cards, sitemap, tracker=published. Verify.
