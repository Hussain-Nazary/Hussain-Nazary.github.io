## What I've automated

- **[Lawyer Assistant](https://lawyers-assistant.github.io)** — legal research automation: answers questions from a firm's own documents with verified inline citations (96% citation accuracy on the project's benchmark suite), via a fully on-device RAG pipeline: BGE-M3 embeddings, ChromaDB, BM25 hybrid search, Ollama. Windows, macOS, Linux; no account, no cloud, no telemetry.
- **[GPT Calendar](https://gpt-calendar.github.io)** — everyday personal workflows automated with on-device AI: a voice-first Android assistant that replaces calendar, reminders, expense tracking, location alerts, and tasks in one app. SMS transactions parse straight into the expense log; AI runs on-device.
- **[GGUFLoader](https://ggufloader.github.io)** — private AI infrastructure: zero-CLI inference engine that runs language models entirely on local hardware — drag-and-drop GGUF loading, live RAM/VRAM dashboard, plugin architecture. The deployment layer behind privacy-sensitive automation.
- **[raw-pytorch-minigpt](https://github.com/hussainnazary2/raw-pytorch-minigpt)** — a GPT-style LLM built from scratch: custom BPE tokenizer, decoder-only transformer, SwiGLU ablations, two-stage fine-tuning. No framework abstractions between the math and the training loop.
- **[LLM-Toolkit](https://github.com/hussainnazary2/LLM-Toolkit)** — MIT-licensed Python toolkit for local LLM workflows and model tooling.
- **Mobile AI Assistant** — Kotlin/Android assistant built for on-device dialogue in underserved languages.

## How I work

- **Understand first.** Map the real workflow — who does it, how long it takes, which tools are involved — before automating anything.
- **Evaluate before trusting.** Every system is measured against real tasks with explicit accuracy targets before deployment. "Works in a demo" is not a standard.
- **Humans in control.** Automation drafts, routes, and flags; people keep the decision points that matter, and uncertain cases escalate instead of failing silently.
- **Private when required.** When sensitive data can't leave your walls, automation runs on local or on-premise models — privacy is architecture, not a policy page.
