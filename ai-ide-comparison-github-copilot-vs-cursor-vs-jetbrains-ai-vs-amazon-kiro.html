AI IDE Comparison (Nov 2026): Copilot vs Cursor vs JetBrains AI vs Kiro vs Antigravity

Last Updated: November 17, 2026 - An up-to-date AI IDE comparison to help you choose the best AI coding assistant for your workflow. This guide compares Amazon Kiro, GitHub Copilot, JetBrains AI Assistant, Cursor, and Google Antigravity, covers where OpenAI Codex fits, and finishes with two budget entrants - Qoder and Freebuff. Every price, plan, and model multiplier below was checked against the vendor's own pricing or documentation page on November 17, 2026.

🌟 Quick Takeaways

  • GitHub Copilot: Now billed in GitHub AI Credits (1 credit = $0.01) - Pro $10, Pro+ $39, Max $100, with Claude Code and Codex available as third-party agents
  • Cursor: New plans come through The X Subscription (Plus $8 → Ultra $200); Grok and Composer ride the usage pool, frontier Claude/GPT/Gemini bill at API list price
  • Amazon Kiro: Credit model with a new Pro Max ($100 / 5,000 credits) tier and team credit pooling; multipliers from 0.05× to 6×
  • JetBrains AI: Still the simplest math (1 AI credit ≈ $1) plus BYOK, local models, and ACP agents that need no AI subscription
  • Google Antigravity: Out of preview and generally available with a $0 tier, Google AI Pro/Ultra quotas, and Gemini 4 Carbon/Argon/Hydrogen
  • Qoder & Freebuff: The budget end of the list - Qoder from $10/month with credits and BYOK, and Freebuff at €0 with 5 ad-funded agent-hours a day

What Changed Since the February Edition

The February version of this comparison was already out of date by spring. Seven things changed the buying decision:

  1. Copilot dropped premium requests. Chat, agent mode, code review, Copilot CLI, and Copilot in the cloud now draw on GitHub AI Credits at $0.01 each, and a new Max plan sits above Pro+.
  2. Cursor became part of The X Subscription. Free, Plus, Premium, Super, Ultra, and Teams now bundle Cursor, Grok, and X. Existing Pro/Pro+/Ultra customers keep their old plans and monthly pools.
  3. The model layer moved twice. Opus 4.6 → Opus 5.5 (September 2026), Sonnet 4.6 → Sonnet 5.5, plus Claude Fable 5.2 (November 9, 2026). OpenAI shipped GPT-6.1 Sol/Terra and GPT-6 Astra; Google shipped Gemini 4 Argon, Carbon, and Hydrogen; xAI shipped Grok 4.7.
  4. Antigravity left preview. It is now a full platform (app, CLI, IDE extensions, Python SDK) that is generally available with a free tier and paid Google AI plans.
  5. Codex merged into ChatGPT Work. One ChatGPT subscription now covers Codex and Work, sharing the same usage allowance. GPT-5.5 was retired from Codex on October 14, 2026.
  6. Kiro and JetBrains both expanded governance. Kiro added Pro Max, credit pooling, and enterprise model controls; JetBrains added the ACP registry so external agents can run inside its IDEs without a JetBrains AI plan.
  7. Two budget entrants joined the list. Qoder (Alibaba) sells an agentic coding platform from $10/month, and Freebuff (built on Codebuff) gives away 5 agent-hours a day funded by ads instead of subscriptions.

📌 How to read this guide: Six vendors now meter AI with different units. GitHub AI Credits are pennies; JetBrains AI credits are roughly dollars; Kiro credits are $0.04 each but are consumed at model-specific multipliers; Cursor uses a shared weekly usage pool; Freebuff counts agent-hours. The only fair comparison is cost per completed task, so treat the headline credit counts as capacity hints, not prices.

✨ What still separates the tools:

  • Model access - which frontier and open-weight models you can actually select
  • Metering - credits, multipliers, weekly pools, or per-seat allowances
  • Repo-scale reliability - how the agent plans, verifies, and stays coherent across many files
  • Governance - admin controls, pooled usage, audit logs, and data-residency options

Amazon Kiro: Spec-Driven Development with Credits

Amazon Kiro is a spec-driven AI coding tool built around two modes: “Vibe” for fast iteration and “Spec” for structured planning, plus steering files that keep larger projects consistent. Instead of flat-rate “unlimited” promises, it uses a transparent credit system where stronger models cost more credits per request. Kiro now ships as an IDE, a CLI, Kiro Web, Kiro Mobile, and Kiro Crew.

What Makes Kiro Different

🎯 Spec-Driven Workflow

Switch between “Vibe” (quick iterations) and “Spec” (structured planning) depending on how you build.

📋 Steering + Skills + Powers

Steering files, Agent Skills, hooks, and Powers keep architecture and conventions consistent across large codebases.

🤖 Auto Routing or Manual Choice

Auto routes to frontier models with fallback (Sonnet-class on Free, Opus-class on paid). Or pin an exact model and pay its multiplier.

💳 Credit-Based Limits

Free monthly credits, per-model multipliers, $0.04 add-on credits, and team credit pooling.

Pricing Options

🎁 Free trial: When you first upgrade to Pro, you get the rest of the month free plus 500 trial credits you can use within 12 months.

  • Free: $0/month, 50 credits/month, open-weight models and Claude Sonnet 4.5
  • Pro: $20/month, 1,000 credits/month, premium models
  • Pro+: $40/month, 2,000 credits/month, premium models
  • Pro Max: $100/month, 5,000 credits/month, premium models
  • Power: $200/month, 10,000 credits/month, premium models
  • Add-on credits: $0.04 per credit (Pro and above)
  • Teams: $20 per seat/month for credit pooling, 500 included credits per seat, $0.04 per additional credit

💼 Ideal For: Developers who like structured planning and want visible, per-model cost control - especially teams that want to pool credits instead of buying identical seats.

GitHub Copilot: Widest Reach, Now Billed in AI Credits

GitHub Copilot remains the default choice for many developers because it works across the widest set of editors - VS Code, Visual Studio, JetBrains IDEs, Xcode, Neovim, Eclipse, Raycast, SSMS, and Zed. The big 2026 change is billing: premium requests are gone, replaced by GitHub AI Credits where 1 credit = $0.01 USD.

Why Developers Choose Copilot

⚡ Fast Inline Completion

Unlimited completions and next-edit suggestions on every paid plan.

🔄 Works Everywhere

One subscription across editors, the CLI, github.com, GitHub Mobile, and the Copilot app.

🤖 Agent Workflows + Fusion

Agent mode, MCP support, code review, and Copilot Fusion Standard/High/Max for progressively deeper reasoning.

👥 Third-Party Agents

Access Claude Code and Codex as third-party agents on Pro; delegating cloud tasks to them is a Pro+ feature.

Plans & Limits

🎯 How credits work: Agent mode, code review, Copilot in the cloud, Copilot CLI, and the Copilot app consume GitHub AI Credits, with usage varying by model. Paid plans include a base credit allotment plus a flex allotment that can change over time; unused credits do not roll over. At $0.01 per credit, Pro's $15 allowance is roughly 1,500 credits, Pro+ is about 7,000, and Max is about 20,000.

JetBrains AI: Deep IDE Integration + Bring Your Own Model

JetBrains AI is the best option if you already live in IntelliJ IDEA, PyCharm, WebStorm, Rider, GoLand, or other JetBrains IDEs. It combines hosted cloud models with bring-your-own-key, custom/local models, and the ACP registry, which lets you install external agents without a JetBrains AI subscription at all. AI Assistant and the Junie agent are folded into one subscription.

Unique JetBrains Advantages

🔒 Custom/Local Models + BYOK

Point AI Assistant at third-party providers, a local model, or your own API key for privacy-sensitive work.

🧩 ACP Registry

Install ACP-compatible agents (including Codex) from the registry; running them does not require a JetBrains AI plan.

🎨 Native Integration

Deep IDE integration for refactors, navigation, commit messages, and documentation - where context matters most.

🤖 Junie Agent

An autonomous coding agent for multi-step tasks, included from AI Pro upward.

Pricing Structure

Individuals:

  • AI Free: 3 AI credits per 30 days; unlimited code completion (not available in Android Studio or Community Editions)
  • AI Pro: $10/month, 10 AI credits per 30 days, Junie included
  • AI Ultimate: $30/month, 35 AI credits per 30 days, Junie included

Organizations:

  • AI Pro: $20/month, 20 AI credits per 30 days
  • AI Ultimate: $60/month, 70 AI credits per 30 days
  • AI Enterprise: $60, part of JetBrains IDE Services, with a quota on par with Ultimate or higher

🎁 Tip: One AI credit equals about $1 USD, which buys roughly 10 code generations in AI Chat, ~40 editor generations, ~25 explain-code requests, or ~280 documentation writes. Purchased top-up credits stay valid for 12 months. Save cloud credits for hard reasoning and use completion plus local models for everyday edits.

💼 Ideal For: JetBrains power users, teams standardizing on one IDE suite, and organizations that need local-model or BYOK options. Note: the JetBrains AI service has not been available in China since July 13, 2026 - BYOK, custom/local models, and ACP agents still work there. Organizations migrating to JetBrains Central get a shared credit pool with per-user limits instead of individual quotas.

AI code reviews and code hosting built into the same subscription, alongside the Grok Bot.

⚡ Weekly Usage Pool

One allowance shared across the editor, CLI, Cloud Agents, Grok Bot, and the Grok apps; it refreshes weekly.

Qoder and Freebuff: The Budget End of the List

The five tools above are the mainstream choices. Two newer entrants matter if price is the deciding factor: Qoder, Alibaba's agentic coding platform with credit plans that start at $10/month, and Freebuff, Codebuff's ad-funded agent that costs €0 and meters usage in agent-hours instead of credits. OpenAI Codex: Part of ChatGPT Work, Not an IDE

OpenAI Codex is a software engineering agent that now lives inside the ChatGPT subscription family. ChatGPT Work and Codex share one usage allowance, so there is no separate Codex bill. It runs in the ChatGPT desktop app (local chats), on the web, in the Codex CLI, in the IDE extension, in Codex Cloud, and via an API key for CI or shared environments.

  • Free / Go ($8/month): GPT-6 Luna at Standard speed in the desktop app, for quick coding tasks.
  • Plus ($20/month): Codex on web, CLI, IDE extension, and iOS; GPT-6.1 Sol, GPT-6 Luna; cloud integrations such as automatic code review and Slack; extra usage via credits.
  • Pro (from $100/month, up to $500): No five-hour limit; Ultrafast mode on the $500 tier.
  • Business / Edu / Enterprise: Per-seat or flexible credit-based pricing, with admin controls, analytics, and compliance tooling.
  • API key: Pay standard API rates; no cloud features (GitHub review, Slack) but full automation support.

Frequently Asked Questions (FAQ)

What changed in AI IDE pricing in late 2026?

Three structural changes: GitHub Copilot replaced premium requests with GitHub AI Credits (1 credit = $0.01) and added a $100 Max plan; Cursor moved new subscriptions into The X Subscription (Plus $8, Premium $30, Super $100, Ultra $200) while honoring legacy Cursor plans; and Kiro added a $100 Pro Max tier plus team credit pooling.

What are the current GitHub Copilot plans and prices?

Copilot Free includes 2,000 completions a month plus limited chat and agent use. Pro is $10/month with $15 of monthly AI credits, Pro+ is $39/month with $70 in credits, and Max is $100/month with $200 in credits.
